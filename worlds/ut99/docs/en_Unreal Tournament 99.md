# Unreal Tournament 99

Play Archipelago in standalone UT99 bot matches: Deathmatch, CTF, Domination, and Assault.
 Win enough maps to finish the seed. 
 Each map has win and frag checks. Other modes add objective checks. 
 Selected item spawns are checks too.

Requires UT99 with OldUnreal 469e. See [setup](setup_en.md).
