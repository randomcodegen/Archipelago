# Unreal Tournament 99 setup

## Install

1. Use UT99 with OldUnreal 469e
2. Put `ut99.apworld` in Archipelago's `custom_worlds` folder and restart it
3. Copy the client ZIP's `System` folder content to UT99's `System` folder
4. Generate a seed with the matching YAML and host it

## Play

Open **Mods > Archipelago**. 
Enter server, port, exact slot name, and optional password. 
Connect, then select an unlocked map. 
**FIRE** after a match replays it for missed checks. 
The menu and HUD show checked / in-logic (total) checks.

See the client [README](https://github.com/randomcodegen/UT99_AP_Client/blob/main/README.md) for console commands and more info.
