# Unreal Tournament 99 setup

## Install

1. Install [UT99 with the OldUnreal Patch](https://www.oldunreal.com/downloads/unrealtournament/full-game-installers/):
    - UT99AP-client-1.0.0.zip is for OldUnreal [469e](https://github.com/OldUnreal/UnrealTournamentPatches/releases/tag/v469e)
    - UT99AP-client-1.0.0-x64.zip is for OldUnreal [469f RC5](https://github.com/OldUnreal/UnrealTournamentPatches/releases/tag/v469f-rc5)
2. Put `ut99.apworld` in Archipelago's `custom_worlds` folder
3. Copy the client ZIP's `System` folder content to UT99's `System` folder
4. Use `Generate Template Options` in the Archipelago Launcher
5. Generate a seed with the matching YAML and host it

## Play

Open **Mods > Archipelago**. Enter server, port, exact slot name, and optional password.
Connect, then select an unlocked map. **FIRE** after a match replays it for missed checks.
The menu and HUD show checked / in-logic (total) checks.

See the client [README](https://github.com/randomcodegen/UT99_AP_Client/blob/main/README.md) for console commands and more info.
